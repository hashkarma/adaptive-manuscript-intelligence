# Golden Success Input

Canonical input assets used by the professor-showcase Golden Success case.

- `manuscript.png` — full original manuscript page.
- `line1.png` — bounded single-line input used for focused HTR checks.
- `asset_manifest.json` — immutable hashes for provenance verification.

These are input data, not generated evidence. Frozen execution evidence is
stored separately under `showcase/cases/golden_success/`.
